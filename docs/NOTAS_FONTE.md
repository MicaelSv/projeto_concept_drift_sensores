- Aula 05: exige RQ, hipótese, baselines, avaliação temporal e análise crítica; o projeto é da Modalidade A.

- Seção 4: SVM multiclasses e comparação temporal; certos lotes são pequenos e faltam classes.
- O trabalho final deve respeitar o limite informado pelo grupo de 8 páginas; o roteiro foi compactado para esse espaço.
